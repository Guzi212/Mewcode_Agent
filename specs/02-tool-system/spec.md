# MewCode 工具系统 Spec

## 背景

MewCode 已打通“人 ↔ LLM”的终端对话闭环：支持多协议、流式输出和多轮上下文，但模型仍只能生成文字，无法触碰文件系统或执行命令。

本阶段为 MewCode 加入工具系统。用户提问后，模型能读文件、写文件、修改文件、执行命令、按模式查找文件和搜索代码内容。模型识别所需工具，应用执行并回灌结果，模型据此给出最终答复，使 MewCode 从聊天机器人变为能处理当前项目工作的 Agent。

## 目标

- 提供统一的工具抽象：每个工具暴露名称、供模型理解的描述、输入参数规则和执行入口。
- 落地六个核心工具：读文件、写文件、改文件、执行命令、按模式找文件、搜代码内容。
- 提供集中注册与发现能力：登记工具、按名称查找，并导出为各 LLM API 可识别的工具定义。
- 以超时和结构化结果保障执行：无论成功还是失败，结果均回传模型，应用和会话不中断。
- 支持 Anthropic 和 OpenAI 协议的完整工具调用流程，并保持一致的上层体验。
- 完成一次工具调用批次与一次最终答复构成的单轮闭环；不实现多轮连环调用的 Agent Loop。
- 在 TUI 中以清晰、简洁的工具行呈现工具调用和结果摘要。

## 功能需求

- **F1（工具抽象与注册）**：系统提供统一的工具抽象。每个工具均声明名称、说明、输入参数规则和执行入口；一个注册中心集中登记全部工具，支持按名称查找，并能导出当前协议 API 可识别的工具定义列表。

- **F2（六个核心工具）**：系统提供以下固定工具集：
  - **读文件**：给定路径，返回文本内容及行号，便于模型引用；文件不存在、不可读或不是文本文件时返回结构化错误。
  - **写文件**：给定路径与内容，创建或覆盖目标文件；缺失的父目录自动创建。成功后返回写入摘要，失败时返回结构化错误。
  - **改文件**：给定路径、原文片段与新文片段，对原文片段进行唯一匹配替换。匹配零次或多于一次时不写入，返回实际匹配次数与清晰错误。
  - **执行命令**：给定命令，在默认工作目录或经授权的外部路径范围内执行并受超时约束；返回标准输出、标准错误和退出码。超时或非零退出返回结构化结果，不中断会话。
  - **按模式找文件**：给定 glob 模式，返回匹配到的文件路径列表。
  - **搜代码内容**：给定搜索模式及可选路径范围，在文件内容中检索，返回命中的文件、行号和文本内容。

- **F3（系统级沙箱与外部路径授权）**：所有工具及其启动的命令子进程均在平台原生的系统级沙箱中执行。默认“工作区”权限允许当前工作目录读写、系统临时目录写入，并禁止工具网络访问。模型请求访问工作目录外内容时，系统解析真实路径和所需读、写或执行权限，在 TUI 展示工具、目标路径、权限和命令摘要；用户可用方向键选择拒绝、仅本次允许或本会话允许。获准后，仅向本次工具子进程授予所选真实路径及其必要的最小读写范围；授权在会话结束时失效。读授权不得写入，单文件授权不得扩大为父目录授权，符号链接不得绕过限制。未获准、超出授权范围或平台不具备可用沙箱后端时，工具返回结构化错误，绝不无隔离执行。

- **F4（工具定义与提示词注入）**：发起首次对话请求时，注册中心导出的工具定义随请求发送，使模型了解工具及参数形态；内置 system prompt 更新为 Agent 角色，并说明工具使用约定、系统级沙箱、外部路径审批和单轮调用限制。

- **F5（流式工具调用解析）**：流式接收模型响应时，系统正确区分正文文本增量、思考增量和工具调用。工具名称与 JSON 参数可分片到达，系统应拼接并解析为完整的工具调用请求；思考增量继续接收即丢弃，不进入正文或工具结果。

- **F6（工具批次执行）**：模型首次响应可请求一个或多个工具。系统按顺序从注册中心查找并执行全部请求；每个调用均受超时保护，无论成功或失败都生成结构化结果。单个调用失败不得阻断同一批次的其余调用，也不得导致应用崩溃或会话中断。

- **F7（结果回灌与一次续答）**：系统将模型首次响应中的工具调用及对应执行结果按协议要求追加到本轮对话历史，再向模型发起一次请求。模型基于工具结果生成最终文本答复后，本轮结束。

- **F8（单轮上限）**：第二次请求中即使模型再次请求工具，本阶段也不执行、不发起第三次模型请求，并以明确的单轮上限结果结束本轮。多轮连环工具调用与自动 Agent Loop 留待后续章节。

- **F9（TUI 工具呈现）**：对话区以可区分的工具行展示每次工具调用，包括工具名和关键参数（例如文件路径或命令）；执行后展示结果摘要。过长内容按结果体量限制截断，工具行和摘要保留在可滚动的对话历史中。

- **F10（结构化错误反馈）**：文件不存在、路径越界、参数无效、命令超时或失败、改文件匹配数不符、搜索无结果、参数 JSON 无法解析及内部异常均转为结构化结果回灌模型，并在 TUI 以可区分样式提示；程序不崩溃，会话可继续。

## 非功能需求

- **N1（超时与界面响应）**：命令及潜在长耗时工具均有内置合理超时；超时后终止该工具并返回超时结果。工具执行、等待与流式期间 TUI 保持响应、可滚动且不冻结。

- **N2（跨协议一致性）**：Anthropic 和 OpenAI 两种协议均支持工具定义注入、流式调用解析、工具结果回灌、一次续答、错误反馈和 TUI 呈现；切换协议不改变上层行为。

- **N3（健壮性）**：工具参数缺失或类型错误、路径非法、命令报错、流式参数解析失败等情况均以结构化错误处理，不抛出未捕获异常或崩溃堆栈。

- **N4（结果体量控制）**：大文件、长命令输出和大量搜索命中均有内置上限或截断，避免工具结果撑爆模型上下文、内存或终端界面；截断状态在结果摘要中可见。

- **N5（文件完整性）**：写入和修改失败时不得留下部分写入或损坏的目标文件；唯一匹配失败时目标文件内容保持不变。

- **N6（敏感信息保护）**：API 密钥及其他敏感配置不得回显到 TUI、工具结果或日志。工具错误包含足以诊断的问题类别与安全说明，但不泄露敏感内容。

- **N7（可测试性）**：工具及协议适配行为可由自动化测试验证；涉及文件和命令的测试使用隔离工作目录；端到端验收通过 tmux 启动 MewCode 并观察真实对话流程。

- **N8（沙箱一致性）**：系统依据当前操作系统选择相应原生沙箱后端；所有文件工具与命令子进程继承同一文件、网络和环境变量边界。工具子进程不继承 API 密钥等敏感环境变量。

- **N9（兼容性）**：不含工具调用的现有纯文本对话、Anthropic/OpenAI 流式输出和思考内容丢弃行为不得回归。

## 不做的事

- 多轮连环工具调用或自动 Agent Loop：一次工具批次及一次最终答复后即停。
- 授权规则、外部路径白名单或工具集的跨会话持久化与运行时配置；本阶段的外部路径授权仅作用于当前会话。
- MCP server 集成、第三方工具市场、动态加载外部工具和自定义工具。
- 工具调用或回复的中途取消、交互式命令输入、后台长期任务和实时命令输出渲染。
- 工具调用、工具结果或对话历史的跨会话持久化。
- 工具行的折叠、展开或详情交互。
- 工具并行执行优化；同一批次工具按顺序执行即可。
- 超时时长的用户配置；本阶段使用内置合理默认值。
- 二进制文件编辑、图片等多模态工具结果和语义搜索。
- 文件版本控制、撤销/重做、自动备份、冲突合并，以及搜索索引或缓存。

## 验收标准

- **AC1（F1）**：注册中心可列出全部已登记工具并按名称查找；首次请求体含六项工具的完整定义，分别符合 Anthropic 与 OpenAI 的协议格式。
- **AC2（F2-读）**：读文件工具返回指定文本文件的内容和行号；读取不存在、不可读或非文本文件时返回结构化错误且应用继续运行。
- **AC3（F2-写、N5）**：写文件工具可新建或覆盖文件，并自动创建缺失父目录；写入失败时既有目标文件内容保持完整。
- **AC4（F2-改）**：原文唯一匹配时只替换该处；匹配零次与多于一次时分别返回匹配次数明确的错误，且文件内容不变。
- **AC5（F2-执行、N1）**：执行命令返回标准输出、标准错误与退出码；故意超时的命令被终止并返回超时结果，界面和会话不挂死。
- **AC6（F2-找/搜）**：glob 模式返回匹配文件；内容搜索返回命中的文件、行号和文本内容；无结果时返回结构化结果。
- **AC7（F3、N8）**：默认工作区权限下，访问工作目录外路径时 TUI 显示工具、真实目标路径和所需权限的方向键审批；拒绝后返回结构化错误且外部文件不被触碰。仅本次授予外部文件的读权限后可读取但不能写入；本会话授予目录写权限后允许该目录内后续操作；会话结束后授权失效。符号链接、命令子进程和未获准外部路径均不能绕过系统级沙箱；缺少可用沙箱后端时拒绝执行而非无隔离执行。
- **AC8（F4、F5）**：一次需要工具的真实提问中，模型收到工具定义和更新后的 Agent 提示词；工具名称与分片到达的 JSON 参数被正确拼接为完整调用，正文与思考增量不混淆。
- **AC9（F6、F7）**：端到端执行“读取指定文件并总结”：模型请求读文件，应用执行并回灌结果，模型第二次请求生成且仅生成体现文件内容的最终文本答复。
- **AC10（F6）**：首次模型响应同时请求多个工具时，所有请求按顺序执行；其中一个失败不阻断后续调用，结果均被回灌。
- **AC11（F8）**：最终答复阶段再次请求工具时，不执行该调用，不发起第三次模型请求，并以清晰的单轮上限结果结束本轮。
- **AC12（F9、N4）**：每次工具调用在对话区显示工具名、关键参数和结果摘要；过长文件、命令输出或搜索结果被截断并标明，历史可滚动查看。
- **AC13（F10、N2、N3）**：分别在 Anthropic 与 OpenAI（含兼容端点）配置下触发不存在文件、命令非零退出、参数错误和修改匹配失败；均以结构化结果回灌、TUI 可区分提示、程序不崩溃且下一轮仍可对话。
- **AC14（N6、N7、N9）**：自动化测试不泄露配置中的 API 密钥；通过 tmux 进行一次真实工具任务端到端测试；原有纯文本流式对话和思考内容丢弃测试继续通过。
